# Is the live AI camera in the report builder the same as the one in the field tool?

**Short answer: yes.** They are not two separate cameras someone built twice — they both run off one single piece of code (one file, `components/AILiveInspectionCamera.tsx`). The actual camera view, the AI write-up logic, the zoom/focus/flash controls, the crash-safety logging, and the "save this to the report" behavior are 100% identical either way. If the camera takes a good photo and writes a good finding in one place, it will do the exact same thing in the other, because it genuinely is the same thing.

The only differences are in how each screen presents it to you — not what it does once it's open.

## Summary
I checked the actual code for both screens side by side. Both the Field Tool and the Report Builder hand the same camera the same options (Findings, Limitations, Equipment, Reference capture are all available in both), and both save a finished finding/limitation/photo the exact same careful way — write it to the phone first, upload in the background, never lose the photo. The only real differences are cosmetic: how you open it, and what it looks like the instant it opens.

## What's actually different between the two

### How you get into the camera, and what it looks like on arrival
- **What's happening:** In the Field Tool, the live camera is one of several tabs built right into that screen — it starts collapsed as an "Open AI Camera" card you tap, and when you're done, it just folds back down into that same tab (the screen stays open). In the Report Builder, there's a separate "📷 Live Camera" button that pops the camera up full-screen and jumps straight to the shutter the instant you tap it — no extra tap needed — and when you're done, it disappears completely rather than collapsing.
- **Why it matters to you:** It's purely a "which door do I walk through" difference, not a quality difference. The Report Builder's version is one tap faster to actually start shooting; the Field Tool's version stays visible as a tab so it's easy to flip back and forth between the camera and your other field-tool screens (voice notes, checklists, etc.).
- **How urgent:** No action needed — this is just how each screen was designed to be used, not a mistake.
- **Where it is:** Field Tool screen (`app/field/page.tsx`) vs. the "Live Camera" button inside a report (`components/ReportBuilderLiveCamera.tsx`).
- **What I'd do:** Nothing — this is intentional and both work correctly.

### "Combine with an existing issue" works the same in both
- **What's happening:** Both versions can offer to attach a new photo to an issue you already wrote up earlier in the same report, instead of creating a brand-new one. I checked this carefully since the two screens load that list of existing issues slightly differently under the hood, but the end result and the AI behavior are the same in both places.
- **Why it matters to you:** You can trust this feature equally whichever screen you're using it from.
- **How urgent:** No action needed.
- **Where it is:** Both screens, wired to the same camera component.
- **What I'd do:** Nothing.
